# HarnessMesh Trademark and Branding Policy

This policy applies to the names, logos, icons, visual identity, and other
branding elements used to identify the HarnessMesh project (the “HarnessMesh
Marks”). It supplements the Apache License 2.0; it does not replace or modify
the software license.

## Permitted use

You may use the name “HarnessMesh” to accurately refer to this project, for
example:

- “HarnessMesh integration”
- “Plugin for HarnessMesh”
- “Compatible with HarnessMesh”
- “A fork of HarnessMesh”

You may use unmodified project screenshots and documentation excerpts for
technical explanation, provided that the source is attributed and the use does
not imply endorsement.

## Restrictions

You may not, without written permission:

- imply that a product, service, fork, plugin, or hosted offering is produced,
  sponsored, certified, or endorsed by the HarnessMesh maintainers;
- use the HarnessMesh logo or visual identity as the primary brand of another
  product or service;
- name a modified distribution “HarnessMesh” in a way that suggests it is an
  official release;
- register or use a confusingly similar company, product, domain, package, or
  social-media name;
- alter project logos and present the result as official project branding.

Modified distributions should use a distinct product name and may describe
themselves as “based on HarnessMesh” or “a fork of HarnessMesh”. Plugins and
integrations should use descriptive names such as “Example Plugin for
HarnessMesh”, not names that imply official status.

## Official releases and domains

Only releases published through the official project repository and release
channels should be presented as official HarnessMesh releases. The Apache
license grants rights to the code; it does not grant rights to project names,
logos, or endorsement.

## Reporting misuse

Please open an issue in the project repository with the relevant URL or
artifact when you see branding that may confuse users about origin,
endorsement, or official status.

This document is a project policy, not a legal opinion. Trademark rights and
enforcement can vary by jurisdiction.
