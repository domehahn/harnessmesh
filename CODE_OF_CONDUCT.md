# Code of Conduct

## Our standard

We are committed to a welcoming, respectful, and harassment-free community. Participants are expected to communicate constructively, assume good faith, respect different viewpoints, and focus criticism on ideas and code rather than people.

Unacceptable behavior includes harassment, discrimination, threats, personal attacks, doxxing, sexualized conduct, publishing private information, and deliberately disrupting project collaboration.

## Enforcement

Project maintainers may edit or remove comments, close issues, restrict participation, or take other action when behavior violates this code. Reports should be made privately to the repository maintainers through the security contact or a private GitHub channel. Please include links, dates, and any relevant context.

Retaliation against a good-faith report is not acceptable.
