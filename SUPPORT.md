# Support

Use GitHub Issues for reproducible bugs and feature requests. Use GitHub Discussions for design questions, configuration help, and general usage questions when Discussions are enabled.

Before requesting help:

1. Read the [README](README.md) and [troubleshooting guide](docs/troubleshooting.md).
2. Run `harnessmesh doctor` and include the relevant redacted output.
3. Include HarnessMesh version, operating system, Go version, adapter versions, and the smallest reproducible configuration.
4. Remove API keys, tokens, source code, transcripts, personal data, and private repository paths.

Do not report security vulnerabilities in a public issue. Follow [SECURITY.md](SECURITY.md) instead.
