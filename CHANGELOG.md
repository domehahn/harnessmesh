# Changelog

All notable changes to this project will be documented here.

## [0.1.0] - 2026-09-18

### Added

- Initial HarnessMesh project.
- Claude Code and Codex CLI adapters.
- Executor/reviewer collaboration loop.
- Structured review schema and evidence-oriented findings.
- Repository context projection and optional test capture.
- Session/thread continuation.
- Max-round, timeout, wall-time and repeated-finding guards.
- Local JSON and Markdown run reports.
- Optional NVIDIA NeMo Switchyard endpoint integration.
- CI, CodeQL, Dependabot and GitHub templates.
